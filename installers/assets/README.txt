Ultrasound Grader README
Author: Victoria Hurd
Last Edited: 2/11/2026

There are two versions of the Ultrasound Grader app:
1. "Ultrasound Grader (Apple Silicon).app"
2. "Ultrasound Grader (Intel x86).app"
Be sure the version you downloaded fits your computer's architecture.
 - Check this by clicking the Apple symbol in the top-left
 - Click "About this Mac"
 - "Chip" or "Processor" should indicate if you have Apple Silicon (M1,2,3) or Intel

Installation & Run Instructions:
1. Simply drag the Ultrasound Grader .app into your Applications folder.
2. Double-click the .app to run it (note that startup time may take 30 sec for Intel).
3. If you get permissions errors (ie. "[Ultrasound Grader] cannot be opened because it is from an unidentified developer"), 
    3a. Navigate to System Settings -> Privacy & Security
    3b. Scroll down to the Security section
    3c. Click "Open Anyway" for Ultrasound Grader. 
    3d. Enter your password or passkey to bypass security settings. This will ONLY change your settings for this app, nothing else. 
    3d. If the "Open Anyway" button does not appear, try closing Settings and retrying steps 3a-3d. 
    3e. Try to open Ultrasound Grader again.
    3f. Click "Open."
    Note: You will only have to follow Step 3 once. 

To uninstall:
1. Open the application.
2. Click "Uninstall" on the main page. 
3. Click "Yes" to continue. This will delete all saved Application Support data. The app will open a final popup message that saved Application Support data has been deleted.
4. The app will open your Applications folder then quit. Drag the app from Applications to the Trash. 
5. There may be remaining files in your Downloads folder. Delete anything you don't need, but be sure not to delete any important results files!
